**Group Project**

**Topic:** Comparison of Random Forest, Support Vector, and K-Nearest Neighbors Classifiers on Sentinel-2 Satellite Imagery \
**Objective:** Land cover classification using satellite imagery is a vital application of remote sensing and machine learning. Accurate identification of surface types, such as forests, sea/lakes, highways, and residential zones, allow governments and organizations to monitor environmental change, plan infrastructure, and assess agricultural conditions. \
\
The goal of this project was to apply several optimized supervised classification models to Sentinel-2 satellite imagery and compare their performance against the target data. Comparisons between the models’ accuracies, precision, recall, f1-scores, ROC, and AUC were made, while identifying the strengths and weaknesses in each approach. This involved analyzing the models’ behaviour under different levels of complexity and regularization. \
**Dataset:** https://www.kaggle.com/datasets/apollo2506/eurosat-dataset?resource=download-directory&select=EuroSATallBands \
**Summary:** \
- Developed end-to-end supervised learning pipeline for land-cover classification of Sentinel-2 satellite imagery, including preprocessing, stratified train-test splitting, and reproducible model training \
- Trained and compared Random Forest, Support-Vector Machine, and k-Nearest Neighbor classifiers; performed model tuning and feature workflow iteration to optimize generalization \
- Evaluated performance via accuracy, precision/recall, F1-score, ROC AUC, and confusion matrices, and delivered a benchmark comparison and recommended model choice based on above metrics and performance for land-cover classification of imagery
