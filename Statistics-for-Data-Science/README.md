*Author: Craig Vande Ligt*

**Topic:** Predictors of Entry into Medication-Assisted Therapy Based on Diagnoses of Opioid Dependence \
**Objective:** To determine which factors predict entry into treatment for opioid dependence using medication-assisted therapy (i.e. use of opioid replacement medication such as methadone or buprenorphine). Exploratory data analysis and initial logistic regression models will be built to evaluate key metrics. A final logistic regression model will then be created to determine the predominant factors. \
**Dataset:** \
https://www.samhsa.gov/data/data-we-collect/teds-treatment-episode-data-set/datafiles \
https://www.samhsa.gov/data/system/files/media-puf-file/TEDS-A-2022-DS0001-info-codebook_v1.pdf \
**Summary:** 
- Analyzed a large administrative dataset to identify predictors of entry into methadone/buprenorphine treatment among individuals diagnosed with opioid dependence 
- Implemented categorical data cleaning, missing data handling via mode imputation and “Missing” categories, and reclassified/engineered features to improve model performance and interpretability of results 
- An iteratively refined logistic regression model was developed, and odds ratios and 95% CIs across variables were used for interpreting effects; found geography and insurance status were strong factors associated with treatment access, and communicated limitations and assumptions used to support responsible decision-making
